Mac apps, at home on Cutefish.

Reef is the part of Cutefish that runs apps made for the Mac. They open in normal windows, put their menus in the menu bar and sit in the Dock, like every other app.

See which apps runDownload Cutefish

Get started

  1. Download a Mac app from its developer's website.
  2. Open its disk image or zip file in Files and drag the app into Applications, as you would on a Mac.
  3. Open the app. The first time, Files offers to install Reef with one click, a download of about 65 MB together with the web engine it uses. The app opens right after.

Reef runs on amd64 and arm64 computers. On amd64 it runs an app's Intel or Universal build; on arm64, its Apple silicon or Universal build. Software Update keeps Reef up to date with the rest of Cutefish.

How it works

No emulation
A Mac app's own machine code runs directly on your processor, the same way a Linux program's does; it isn't emulated or translated. Only shaders written for Metal, Apple's graphics interface, are converted when they load.
Reef's own frameworks
Reef provides the parts of macOS that apps call into, such as AppKit, Foundation, SwiftUI, Core Data and Metal, written from scratch.
Part of the desktop
Cutefish's toolkit draws the apps' windows and controls, and its compositor and shell give them the same shadows, animations, menu bar and Dock as every other app.

How Reef is made

Three things hold for all of Reef.

Built without taking Apple's software apart
Reef isn't built by disassembling or decompiling Apple's software. How each part should behave comes from Apple's public documentation, the source code Apple publishes, and running apps and test programs on a Mac to compare what they do. Reef's code isn't written from the source of other projects that reimplement macOS; what can be learned from those projects is used only as written notes on behavior, never as code.
No proprietary Apple software
Reef contains no files taken from macOS and nothing from Apple's developer kit; the only Apple code in it is the open source below. It needs no Mac, macOS installer or Apple account, and Cutefish doesn't distribute any Mac apps: you download them yourself.
Apple's open source, under its licenses
Some of Reef is code Apple publishes as open source: Core Foundation, libdispatch, the Swift standard library and runtime with its framework overlays, parts of swift-foundation, LZFSE, locale data from Apple's ICU, and one file based on IOHIDFamily. The package includes each license in full, and the source of that one file, as the Apple Public Source License requires.

How you can check

Reef's source code isn't public, so you can't read how it was written. You can check what it contains.

  • Reef's package is public: on Cutefish, apt download cutefish-reef fetches it without installing it. It is a 14 MB download, and none of the Mac-format files in it carries a code signature, while Apple signs the system software it ships.
  • Its libraries keep their internal names: the 196 Mac-format files hold more than 300,000 symbols, nearly 100,000 of them the names of internal functions and methods. Anyone can open them in a disassembler and compare them with Apple's.
  • Its folder /usr/share/doc/cutefish-reef lists every open-source component it includes, with each license in full and the source of the one file under the Apple Public Source License.
  • It installs and runs on a computer that has never had macOS on it, with no Apple account.

What won't work

Reef doesn't cover all of macOS yet; the compatibility list shows the apps tested so far and how well each one runs. Apps built only for Apple silicon don't run on amd64 computers, and apps built only for Intel don't run on arm64. Nor does anything that goes through Apple's servers: the App Store, in-app purchases, iCloud and Sign in with Apple. Apps that sell licenses on their own website or sync through their own service aren't affected. AppleScript doesn't run either.

Free, not open source

The rest of Cutefish is open source. Reef is free to use. Its source code isn't public yet, but it will be open-sourced in the future.

I've put a lot of time and effort into building Reef on my own, and it is still changing quickly as more apps are tested. Keeping it closed for now protects that work, lets me move fast, and gives Cutefish something distinct of its own until it is ready to open up.

If you would rather not run closed-source software, you don't have to install it: Reef is only installed when you agree to it. If you already have, sudo apt remove cutefish-reef removes it.
