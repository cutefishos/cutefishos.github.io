Made with care, from the compositor up.

Cutefish began in 2021 as a Qt and KWin desktop. In 2026, it was rewritten from scratch on Debian — its own Wayland compositor, C++/Skia toolkit, and native apps. It is built for people who want a fast, coherent Linux desktop, especially if you are at home on a Mac.

Who builds it

Cutefish is designed and maintained by Reion Wong, drawing on years of engineering work on Linux desktops and the Android system framework. That background shapes the stack — a unified compositor, Skia rendering, and a native toolkit — while AI coding agents assist with implementation so one person can maintain it from the ground up.

What Cutefish is made of

Compositor
cutefish-compositor is a standalone Wayland compositor that handles the shell, window effects, animations, and display handoff itself — with no GNOME or KDE stack underneath.
Display manager
cutefish-dm starts the login screen, which the compositor draws, and then the session you sign in to.
Toolkit
cutefish-toolkit is a native C++ toolkit rendered with Skia, built for low overhead and crisp fractional scaling. Every Cutefish app is built on it.
Apps
Files, Terminal, Settings, Calendar, Calculator, Clock, Disk Utility, Preview, System Monitor, Text Editor, Video Player, and Screenshot.
Base
Debian, with packages for amd64 and arm64.

Open source

The desktop and its apps are open source. The code and its whole history are public on GitHub. Core components are permissively licensed under BSD 3-Clause so hardware vendors, downstream distributions, and developers can ship or build on Cutefish without licensing friction.
