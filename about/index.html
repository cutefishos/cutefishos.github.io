Made with care, from the compositor up.

Cutefish began in 2021 as CutefishOS. Today it is a Linux distribution built on Debian, for people at home on a Mac, with a desktop that is entirely its own.*

What Cutefish is made of

Compositor
cutefish-compositor is a Wayland compositor that draws the shell, window effects and animations itself.
Toolkit
cutefish-toolkit is a native C++ toolkit drawn with Skia. Every Cutefish app is built on it.
Apps
Files, Terminal, Settings, Calendar, System Monitor, Text Editor, Video Player and Screenshot.
Base
Debian, with packages for amd64 and arm64.

Open source

The desktop and its apps are open source. The code and its whole history are public on GitHub.

Built in the open

Nothing we publish is built on anyone's own computer. A public workflow on GitHub Actions does all of it.

Built
Every package and ISO, from the code on GitHub.
Signed
The package repository, with a key only that workflow can use.
Traceable
Every file records which commit and which build made it, in a public log nobody can rewrite.

So you can check a download yourself instead of taking our word for it.

Get involved

Bug reports, fixes and translations are welcome as issues and pull requests on GitHub. To support the work, you can sponsor Cutefish monthly or once through GitHub Sponsors. For anything else, write to hello@cutefish.org.
