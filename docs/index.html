Cutefish Documentation

Documentation for the Cutefish desktop.

  • Architecture: the processes, libraries and protocols that make up the desktop, and how a frame and an input event travel through them.
  • Building Cutefish from Source: build the desktop and install it on an existing Linux distribution.
